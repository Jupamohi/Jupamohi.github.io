# Portafolio de Juan Pablo Mosquera

Sitio estático (HTML, CSS y un poco de JavaScript) publicado con GitHub Pages en https://jupamohi.github.io

## Publicar

1. Crea un repositorio público llamado exactamente `Jupamohi.github.io`.
2. Sube todo el contenido de esta carpeta a la rama `main`.
3. En Settings > Pages, elige "Deploy from a branch", rama `main`, carpeta `/ (root)`.
4. Espera uno o dos minutos y abre https://jupamohi.github.io

## Pendientes

- Agregar las tecnologías de SkyRush en `index.html` (busca el comentario).
- Agregar el enlace de LinkedIn cuando esté listo.
- Si no quieres la foto, borra la línea `<img src="assets/foto.jpg" ...>` y la sección queda solo con texto.

Las fuentes (Bricolage Grotesque y Newsreader) están incluidas en `assets/fonts` con licencia OFL.
